# boucheriegabonaise — site vitrine statique

Le site internet de la Boucherie Gabonaise : une page d'accueil en HTML et CSS avec des images, un bouton WhatsApp et les coordonnées de contact.

## Pourquoi ce projet
Un site vitrine simple à publier, écrit sans framework (novembre 2023 ; les derniers changements, en mai 2024, concernent le domaine).

## Ce que j'ai appris
- Écrire une page statique complète en HTML et CSS (`index.html`, `main.css`, `styleguide.css`).
- Ajouter un bouton de contact WhatsApp avec un lien `wa.me` / `api.whatsapp.com`.
- Publier un site statique sur un domaine personnalisé (l'historique garde la trace d'essais avec un fichier `CNAME`).

## Stack
HTML et CSS, sans outil de construction. Police Teko (Google Fonts).

## Lancer en local
Aucune installation. Ouvrir `index.html` dans un navigateur, ou lancer un petit serveur :
```bash
python3 -m http.server 8000   # puis http://localhost:8000
```

## Démo
Site de la Boucherie Gabonaise (domaine `boucheriegabonaise.com` d'après l'adresse e-mail du site). Je n'ai pas vérifié qu'il est en ligne.
